# Hari Vignesh — Portfolio

Netflix-inspired developer portfolio built with vanilla HTML, CSS, and JavaScript.

## Setup

1. Copy `Hari_Vignesh_Resume.pdf` into this folder for the resume download to work.
2. Open `index.html` in a browser — no build step needed.

## Deploy to GitHub Pages

```bash
git init
git add .
git commit -m "Initial portfolio"
git branch -M main
git remote add origin https://github.com/Hari-Vignesh214/portfolio.git
git push -u origin main
```

Then in your GitHub repo → **Settings → Pages → Source: Deploy from branch → main → / (root)** → Save.

Your site will be live at: `https://Hari-Vignesh214.github.io/portfolio`
